# Release notes (`docs/develop/release/`)

*Language: **English**.*

These are **historical records** of what shipped in a given version. They describe the system **at
that release** and are not kept in sync with `main`; where a note and the current code disagree,
**the code wins**. For current behaviour use [`../design/11_architecture_overview.md`](../design/11_architecture_overview.md);
for what is still unbuilt see [`../design/14_roadmap.md`](../design/14_roadmap.md).
